Проект реализован в учебной цели изучения Go, и не использовался как-либо.


Запуск на Windows
Сначала запустите:
start-server.bat
Затем:
start-app.bat

Серверная часть реализована через ИИ

Проект состоит из:
- интерфейса на Go и Fyne;
- сервера на Python и FastAPI;
- базы данных SQLite.

Структура проекта
main.go          запуск приложения
internal/ui/     интерфейс
internal/api/    запросы к серверу
internal/model/  структуры данных
assets/          изображения
server/          сервер и база данных
